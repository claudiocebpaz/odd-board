# Website

The odd-board website lives at **https://claudiocebpaz.github.io/odd-board/** (English) and `/odd-board/es/` (Spanish). Its source is a separate, private repository, `claudiocebpaz/odd-board-site`; `.github/workflows/site.yml` builds it and publishes only the built files to this repository's GitHub Pages, so the URL stays `/odd-board/`. Forks skip that workflow. To propose a change to the site, [open an issue](https://github.com/claudiocebpaz/odd-board/issues). Setup and maintenance of the deploy are documented in the private repository.
